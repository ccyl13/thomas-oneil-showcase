# Thomas O'Neil Álvarez — Portfolio

Personal portfolio of Thomas O'Neil Álvarez, Ethical Hacker & Pentester.

## Stack

- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** + **shadcn/ui**
- **Framer Motion** — animations & 3D transforms
- **Three.js** via `@react-three/fiber` — 3D particle network hero
- **React Router v6**

## Local development

```bash
# Install dependencies
npm install        # or: bun install

# Start dev server
npm run dev        # → http://localhost:8080

# Build for production
npm run build
```

## Deploy

GitHub Actions automatically builds and deploys to GitHub Pages on every push to `main`.
